# Facebook Control Lite
تطبيق Android بسيط لفتح Facebook داخل WebView مع لوحة تحكم لحظر الوظائف. صفحات تسجيل الدخول/checkpoint/recover/registration مستثناة من كل الحقن والحظر.

## البناء
GitHub Actions يبني APK تلقائياً عند push إلى main أو يدوياً من Actions > Build APK.

## ملاحظة
Facebook يغير واجهة WebView باستمرار، لذلك بعض الحواجز تعتمد على النصوص/الروابط وقد تحتاج تحديثاً مستقبلاً.
